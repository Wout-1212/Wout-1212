## Projecten

### [Samen voor Tess](https://github.com/Wout-1212/steunactie-tess) *(work in progress)*
* **Tech Stack:** PHP, Kirby CMS, Tailwind CSS, JavaScript, Mollie API, SQLite
* **Omschrijving:** Een website voor een steunactie, met online doneren via Mollie en een CMS. Klantproject in een team van twee bij The Agency (KdG). **Nog in ontwikkeling:** de site staat nog niet live.

### [Discord Coach](https://github.com/Wout-1212/discord-coach-public)
* **Tech Stack:** TypeScript, Cloudflare Workers, Discord API, Claude, Intervals.icu API
* **Omschrijving:** Een persoonlijk project: een Discord-bot waarmee ik via een AI-coach mijn trainingsdata en trainingskalender in Intervals.icu raadpleeg en aanpas. Gebouwd met Claude Code.

### [Laravel Webshop](https://github.com/Wout-1212/laravel-webshop)
* **Tech Stack:** PHP, Laravel, MySQL
* **Omschrijving:** Een e-commerce webapplicatie gebouwd met Laravel voor het beheren en tonen van producten.

### [PHP Event App](https://github.com/Wout-1212/php-event-app)
* **Tech Stack:** PHP, MySQL, HTML/CSS
* **Omschrijving:** Een evenementen-applicatie waarmee gebruikers events kunnen bekijken en beheren.

### [React API App](https://github.com/Wout-1212/react-api-app)
* **Tech Stack:** React, JavaScript, REST API
* **Omschrijving:** Een dynamische frontend applicatie die gegevens ophaalt en verwerkt via een externe API.

### [Vue Student CRUD](https://github.com/Wout-1212/vue-crud-students)
* **Tech Stack:** Vue 3, Vite, Tailwind CSS
* **Omschrijving:** Een studentenbeheersysteem met volledige CRUD-functionaliteit (Create, Read, Update, Delete).
